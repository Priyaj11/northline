## TC-AUTH-005 The error message does not reveal which credential was wrong

**Requirement** REQ-AUTH-002  
**Technique** Negative Testing  
**Layer** security  
**Priority** High  
**Automation** automated (tests/ui/test_login_ui.py::test_the_error_message_does_not_reveal_which_credential_was_wrong)  
**Introduced in phase** 5

**Preconditions** One valid username and one unknown username are available.

**Test data** wrong password on a valid user, and an unknown user

**Steps**

1. Attempt login with a valid username and a wrong password. Record the message.
2. Attempt login with an unknown username. Record the message.
3. Compare the two messages.

**Expected result** Both attempts produce the same message. A different message would let an attacker confirm which usernames exist, which is username enumeration.
